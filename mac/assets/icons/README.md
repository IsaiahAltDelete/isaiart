# Mac icon artwork

31 icons use published artwork saved locally: Apple's current Mac User Guide and MacBook Pro guide supply the native application and utility images, and Microsoft's Mac App Store listing supplies Outlook. Each original image is unaltered; sources.json records its page, image URL, dimensions, retrieval date, and SHA-256 digest. Shared rendering covers the Dock, Apps view, Finder application files, Spotlight, app previews, and notifications.

Calendar retains live weekday/day text over Apple's original tile. The official full Trash artwork appears only when Trash contains files; empty Trash uses a separate transparent vector wastebasket. Other file/folder icons, Mission Control, Time Machine, and the unused legacy Launchpad tile retain vector artwork. System category symbols are separate from application icons.

Most guide images are 60-pixel assets and do not provide native Retina resolution at larger scales. Outlook is 512 pixels. The legacy keychain filename supplies the actual Passwords icon used by this recreation. Alternate Clear/dark/tinted appearances remain browser approximations. The artwork belongs to its respective publishers; source references do not imply affiliation.
