Critic Loop

A skill for Claude that won't call it done until an expert would.

Download critic-loop.skill

What it is

Ask Claude to make something subjective, like a page, a layout, some copy or a game screen, and it usually stops at "looks fine." This skill sets up a second agent whose only job is to be the harshest credible judge in that field: an art director, a staff engineer, a magazine editor. It scores the work from 1 to 10 against a pass mark, and Claude keeps fixing until it passes or runs out of attempts.

The loop

  1. 1Set the rules. Pick the persona, the pass mark (8.5 by default) and the attempt budget (3 by default). Choices you already made are locked so the critic can't argue you out of them.
  2. 2Build and gather evidence. Real screenshots, files or renders the critic can inspect itself, so it grades the work and not the description of it.
  3. 3Get scored. A calibrated scale, a two-line verdict and a ranked list of defects, each tied to something visible.
  4. 4Fix and resubmit to the same critic. It marks each earlier note fixed or not before adding new ones, so the bar doesn't move between rounds.
  5. 5Report honestly. The whole score history (7.1 → 7.8 → 8.6), whether it passed, and what's still on the list.

Install

On claude.ai, upload the .skill file under Settings → Capabilities → Skills. For Claude Code, unzip it into ~/.claude/skills/.

Then just ask: "set up a critic and make this a 9," "grade this," or "you have 3 attempts."
