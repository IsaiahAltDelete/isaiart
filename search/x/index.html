                05
                POST TYPE
            

            


                

                    REPLIES
                    

                        
                        
                        
                    

                    filter:replies / -filter:replies
                


                

                    REPOSTS
                    

                        
                        
                        
                        
                    

                    Search hides reposts by default. include:nativeretweets puts them back; filter:nativeretweets shows nothing else. Reposts are only indexed for about a week.
                


                


                

                    SHAPE

                06
                MEDIA & LINKS
            

            


                

                    MEDIA
                    

                        
                        
                        
                        
                        
                        
                    

                    These stack as AND. filter:images filter:videos asks for a post carrying both.
                


                


                

                    LINKS
                    

                        
                        
                        
                    

                


                

                    
                    
                    Matches the resolved destination, so shorteners are followed. A hyphen in the domain is typed as an underscore: url:t_mobile.com.
                


                
                filter:news — links to X's list of news publishers.

                08
                RESULTS
            

            


                

                    TAB
                    

                        
                        
                        
                        
                        
                    

                    Lands on ?f=. Top is ranked; Latest is the raw reverse-chronological index and is usually what an operator-heavy query wants.
                


                

                    HOST
                    

                        
                        
                    

                    Both resolve to the same index; twitter.com is kept for clients and archives still pinned to it.
                


            

        


        
        

            READ ME
            

                
These operators are a property of the web and app search, not of the public API — v1.1, v2 and Premium Search accept a different, smaller set, so a query built here will not transplant into a script unchanged.

                
Practical ceilings worth knowing: a query holds roughly 22–23 operators before it is truncated; filter:nativeretweets and the card_name: family only reach back about 7–10 days; and a bare time range with no search terms at all tends to return nothing — give it at least one word.
