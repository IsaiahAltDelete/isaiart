                WORDS
            

            


                

                    
                    
                    Every word must appear. Bluesky has no OR — to search alternatives you run two searches.
                


                

                    
                    
                    A quoted phrase also matches image alt text, which is the one place Bluesky searches further than X.
                


                

                    
                    
                


                


                

                    
                    
                


                

                    
                    
                    Exclusions have no operator — they ride as their own URL parameter, which older clients ignore.
                


            

        


        
        

            

                02
                ACCOUNTS
            

            


                

                    
                    
                    Full handles, with or without the @. Several handles widen the search rather than narrowing it — but only as a parameter: a query string keeps just the first from: it meets, so a list is emitted as &author= whichever mode you're in.
                


                

                    
                    
                


                


                

                    
                    
                    to: is an alias for this on Bluesky — it finds mentions, not replies. There is no reply-recipient operator.
                


                

                    
                    
                


                


                

                    AUTHOR SCOPE
                    

                        
                        
                        
                    

                    Both need you signed in — the server resolves me and following from the session, so a shared link means the reader's follows.
                


            

        


        
        

            

                03
                LINKS
            

            


                

                    
                    
                


                

                    
                    
                


                


                

                    
                    
                    Everyone who posted one exact link. Useful for finding the discussion around an article rather than the article.
                


                

                    
                    
                


            

        


        
        

            

                04
                FILTERS
            

            


                

                    
                    
                    Two-letter ISO 639 code, matched against the language the author's client declared — not detected from the text.
                


                

                    REPLIES &replies=
                    

                        
                        
                        
                    

                


                

                    MEDIA &media= &video=
                    

                        
                        
                        
                    

                    Mutually exclusive — a post matches at most one, so these are one control rather than two checkboxes.
                


            

        


        
        

            

                05
                TIME
            

            


                

                    

                        
                        
                    

                    

                        
                        
                    

                

                Both accept a plain date or a full UTC timestamp (2024-04-13T17:00:00.000Z). The date form is interpreted as UTC midnight, so a same-day range needs the day after.

            

        


        
        

            

                06
                RESULTS
            

            


                

                    TAB &tab=
                    

                        
                        
                        
                        
                    

                    People and Feeds ignore the post filters — any filter beyond language hides those tabs in the app.
                


                

                    EMIT AS
                    

                        
                        
                    

                    OPERATORS keeps everything it can inside q, so the query survives being pasted into a search box. PARAMS writes each filter as its own URL parameter, the way the app's own advanced dialog does. Exclusions, the filters with no operator, and any field holding more than one value always ride as parameters either way.
                


            

        


        
        

            READ ME
            

                
Bluesky's search is narrower than X's on purpose, and the gaps are worth knowing before you go looking for a control that isn't here: there are no engagement filters (no minimum likes, reposts or replies), no boolean OR, no wildcards, no geo operators, and no way to search by client or by post shape.

                
What it does have that X does not: a quoted phrase is matched against image alt text as well as post text.

                
The exclusion filters and the replies/media controls are the newer structured parameters the official app writes. They are honoured by the current AppView; a third-party client on the older search path will quietly drop them, so a query that depends on an exclusion should be checked in the official app.
