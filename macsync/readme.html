GitHub Sync for Mac

Keep your GitHub projects on this Mac — no typing commands required.

Once it's set up, you get three things you just double-click:

ButtonWhat it does
Pull From GitHubDownloads the newest version of all your files onto this Mac
Push To GitHubUploads everything you changed, so it goes live
Get New ReposGrabs any brand-new projects you've made since last time

Part 1 — Installing (you only do this once)

What you need first

  • A Mac
  • Your GitHub username and password — you'll sign in through your browser
  • About 5 minutes and an internet connection

Step by step

  1. Unzip the file. Double-click MacGitHubSync.zip. A folder appears next to it — drag that folder somewhere you'll remember, like the Desktop.
  2. Open the folder and find the file called: 1 - INSTALL ME.command
  3. Right-click it (or hold Control and click) and choose Open.
    Important: it must be right-click → Open. If you plain double-click it the first time, macOS will refuse to run it.
  4. A warning appears saying Apple "cannot verify" the file. Click Open (or Open Anyway).
    No "Open" button? Only "Done" or "Move to Trash"?
    1. Open the menu → System Settings → Privacy & Security
    2. Scroll down — you'll see "1 - INSTALL ME.command was blocked…"
    3. Click Open Anyway and confirm
  5. A black Terminal window opens with a big purple SETUP logo. That's the installer. Press Return to begin.
  6. It walks you through five steps:
    • 1. Developer tools — if your Mac needs Apple's free developer tools, a small Apple window pops up. Click Install and wait. This is the slow part. The installer waits for you.
    • 2. GitHub helper — downloads on its own. Nothing to do.
    • 3. Sign in to GitHub — a short code appears (like A1B2-C3D4). Copy it, press Return, and your browser opens GitHub. Paste the code and approve, then come back to the Terminal window.
    • 4. Where to keep things — it suggests Documents/GitHub. Just press Return.
    • 5. Downloading — it lists each project as it arrives.
  7. When the green ALL DONE! box appears, you're finished. A Finder window opens with your projects, and two shortcuts land on your Desktop.
You can throw the MacGitHubSync folder away now if you want — everything you need is in your projects folder and on the Desktop.

Part 2 — Using it day to day

Pull before you start  ·  Push when you're finished

Before you work on anything

Double-click Pull From GitHub. A cyan screen runs through every project and reports UPDATED or ALREADY UP TO DATE. Press Return to close it.

This makes sure you're editing the newest version of your files.

After you've made changes

Double-click Push To GitHub.

  1. It asks what you changed. Type something short like fixed the about page — or just press Return and it date-stamps it for you.
  2. It works through each project: STAGING → COMMITTING → SYNCING → UPLOADING.
  3. Anything you didn't touch says NOTHING TO UPLOAD (clean). That's normal and good.
  4. Press Return to close. Your changes are live within a minute.

When you make a brand-new project on GitHub

Double-click Get New Repos. It checks your account and downloads anything that isn't on this Mac yet.

Where everything lives

ThingWhere
Your projectsDocuments/GitHub (or wherever you chose)

Records of what happenedpull_repos.log and update_repos.log in your projects folder

Troubleshooting

If you see…Do this
"…from an unidentified developer"Right-click the file → Open → Open. Only happens the first time for each file.
It still won't open at allOpen Terminal (Applications → Utilities). Type bash and a space, then drag the file into the window and press Return. This always works.
UPLOAD FAILED / authentication failedYour GitHub sign-in expired. Double-click Get New Repos — it signs you back in — then push again.
CONFLICT — NEEDS A HUMANThe same file was edited in two places. Nothing is lost, but it needs sorting out by hand. Make a note of the project name and get someone to untangle it.
The window closes instantlyThe file lost its "runnable" flag. In Terminal type chmod +x and a space, drag the file in, press Return.
You want a different folder or GitHub accountRun 1 - INSTALL ME.command again. It's safe to re-run any time and won't harm anything already downloaded.

Uninstalling

Nothing is installed system-wide. To remove it completely: delete your projects folder, delete the two Desktop shortcuts, and delete ~/.githubsync.conf plus the hidden ~/.githubsync folder. To sign out of GitHub, run gh auth logout in Terminal.
