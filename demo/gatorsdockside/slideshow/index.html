How it works

From employee to Key HR in one submit

1

Employee fills out the form

Ten guided steps: about you, family, every plan, other coverage, review and sign. Running cost per paycheck the whole way.

→
2

Signs and submits

A signed PDF is built in the browser. The employee downloads their own copy right away.

→
3

Google Sheet

One row per enrollment, every field in its own column.

4

Private Drive folder

The signed PDF is saved and linked from the row.

→
5

Key HR admin

Admin key unlocks every submission, search, Excel export, and each PDF.

Runs on Google Apps Script (free) with the pages hosted on GitHub Pages.

Live demo

Try it in about three minutes

Use made-up details only. Anything entered is visible on the admin page.

  1. Open the formkeyhrsales.github.io/demo/gatorsdockside, or scan the QR code.
  2. About youTry typing letters in salary or ZIP. The form blocks them.
  3. Pick plans or waive"Waive all" is a checkbox. Uncheck it and earlier choices come back.
  4. Watch the totalCost per paycheck updates as each plan changes.
  5. Review and signCheck the three consents and sign with a mouse or finger.
  6. Download the PDFThen open the admin page with key keyhro to see it arrive.

Before it goes live

  • Move the Drive folder and script to a Key HR Google account and redeploy.
  • Replace the demo admin key with a long private key.
  • Load the real plan rates, carriers, deadlines, and plan documents.
  • Point the form at a Key HR domain or page.
  • Clear all demo rows and PDFs, and remove the DEMO banners.
