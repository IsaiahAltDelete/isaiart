# Windows icon artwork

30 icons use Microsoft's own artwork, saved locally as unaltered PNG files and retrieved October 29, 2026. Most come from a Windows 11 build 26300 PC: 256-pixel app-list assets from the installed app packages (Store, Notepad, Calculator, Terminal, Photos, Paint, Clock, Snipping Tool, Weather) and Settings, and the largest frame of the icon resources in explorer.exe, msedge.exe, cmd.exe, powershell.exe, control.exe, Taskmgr.exe.mun, imageres.dll.mun and shell32.dll.mun. Those resource frames are stored as PNG inside the binaries and are written out byte for byte. Shell icons follow the references Windows itself uses (shell folder DefaultIcon registry values and SHGetStockIconInfo). Outlook and Copilot come from their Microsoft Store listings: the installed Outlook package is a 2024 build whose icon still carries a "NEW" badge, and Copilot is not installed.

`sources.json` records each image's source path or page and image URL, dimensions, retrieval date and SHA-256 digest. The emulator loads only these local files and never contacts Microsoft servers at runtime.

Local images are 256 pixels; Outlook is 300 and Copilot is 100 pixels. Windows 11 uses the same image for fixed and removable drives, so `drive.png` and `usb.png` are identical. File-type icons, the known-folder badges and anything not listed in `sources.json` still use the original vector drawings in `scripts/02-icons.js`, which also remain as the fallback for every name. Light, dark and high-contrast variants are not represented.

The artwork belongs to Microsoft. Source references document provenance; they do not imply ownership or affiliation.

Task Manager has its own set, rendered as plain `<img>` tags from `scripts/42-taskmgr.js` rather than through `Win.appIcon`: Teams, Spotify, Steam, HP Smart, Zoom, VLC, Phone Link, Widgets, Windows Security, Realtek, Intel Graphics Command Center, Edge WebView2, Spooler, Search, Search Indexer, and Task Manager's own Service Host and generic-process icons. Installed programs supplied most of them (icon resources in Spotify.exe, steam.exe, SecurityHealthSystray.exe, spoolsv.exe, msedgewebview2.exe and Taskmgr.exe.mun, and package assets for Phone Link, Widgets, Search and Intel). Teams, HP Smart, Zoom, VLC and Realtek come from their Microsoft Store listings. `widgets.svg` is the package's SVG, and the two Task Manager icons are 24-pixel bitmap frames saved as PNG. Third-party artwork belongs to its publishers.
